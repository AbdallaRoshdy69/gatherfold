# Changelog

## 1.0.0 — 2026-09-14

- Added deterministic front/back imposition for folded signatures.
- Added three independent sample book projects and browser persistence.
- Added an interactive sheet canvas with side and density controls.
- Added direct page reassignment with live missing, repeated, and range checks.
- Added undo and redo for immutable book edits and keyboard shortcuts.
- Added page finding across signatures and accessible slot selection.
- Added physical sheet ordering, binder notes, and textual proof approval.
- Added 16-page book extension with automatic imposition.
- Added responsive editor layouts and 32 self-contained tests.
